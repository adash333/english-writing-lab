# 調査記録（research/）

教材や保護者向けページを作るために調べた内容を、出典とともに記録する場所です。ページに書いた説明の根拠をあとから確かめられるようにし、同じ調査を繰り返さないことを目的とします。

## フォルダ構成

| ファイル | 内容 |
|---|---|
| [presentation/sources.md](presentation/sources.md) | プレゼンテーションの調査記録：英国ナショナル・カリキュラムの「話すこと」（Show & Tell のレッスンの根拠） |

新しいテーマ（例：意見文、説明文、プレゼンテーション）を調べたときは、`research/<テーマ名>/sources.md` を作り、この表に追加します。

## 1件の出典の書き方

```markdown
### [番号] 出典名
- **発行者・著者／日付：**
- **URL：**
- **確認日：** YYYY-MM-DD
- **確認方法：** 原文を直接確認 ／ 検索結果の要約のみ ／ 書店・出版社の書誌情報 ／ 記憶による（未確認）
- **原文の引用：** "..."（必要な部分だけ、短く）
- **要点（日本語）：**
- **使用箇所：** どのページのどの説明に使ったか
- **注意点：** 古い情報、出典どうしの食い違い、確認できなかったことなど
```

## 記録のルール

1. **確認方法を必ず書く。** 原文を開いて確かめたのか、検索結果の要約だけなのかを区別します。要約だけの情報は、ページでは断定を避けます。
2. **原文の引用と解釈を分ける。** 出典に書いてあることは「原文の引用」に、自分たちの解釈や教え方の提案は「要点」や教材側に「本教材の解釈」と明記します。
3. **ページ番号・版・ISBNを書く。** PDFは印刷されたページ番号、書籍は版とISBNを記録します。
4. **確認できなかったことも書く。** 「Year 4版の有無は未確認」のように、調べても分からなかったことを残します。
5. **子どもの個人情報は書かない。** 調査記録に、子どもの名前・学校名・作文を含めません。
6. **教材ページの出典番号と対応させる。** 教材ページの出典番号［1］［2］…と、この記録の番号をそろえます。
