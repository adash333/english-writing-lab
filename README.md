# English Writing Lab

**英語圏の学校で学ぶ Writing と Presentation の「型」を、保護者が日本語で学べる無料サイト**

英語圏の学校では、小学校の早い段階から、物語文・意見文・エッセイなど、目的に合わせた文章の組み立て方と、人前での発表のしかたを学びます。このサイトでは、その「型」を日本語で紹介します。英語の課題の言葉は英語のまま載せ、日本語で説明します。

教材は、簡単なものから順に増やしていきます。

## 教材

| 教材 | 対象の目安 | 内容 |
|---|---|---|
| [Show & Tell — はじめての発表](lessons/presentation/show-and-tell.md) | 5〜7歳 | 物を1つ見せて話す。4つの部分、文の型、見本、質問への答え方、チェックリスト |

これから加える予定：Opinion Writing（意見文）の基本、意見を話す短いスピーチ、Essay Writing の基本、スライドを使った発表と質問への答え方。

## このサイトの方針

- 英国の初等英語教育や IB（国際バカロレア）を参考にしますが、同じカリキュラムであるかのようには扱いません。学校ごとの課題と評価表を優先してください。
- 課題の言葉、文章の種類の名前、評価の段階（Beginning / Developing / Accomplished / Exemplary）は英語のまま使い、日本語を添えます。最終目標は、英語の課題に英語で答えることです。
- 例文や見本は、このサイトのために書いたオリジナルの架空の例です。子どもの作文や個人情報は載せません。
