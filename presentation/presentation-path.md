# Presentation pathway

| Stage | Task | Core skills |
|---|---|---|
| Primary | Show & Tell | sequencing, eye contact, simple visuals |
| Upper primary | Informative / persuasive speech | opening, reasons, closing, timing |
| Middle school | Debate / research presentation | evidence, rebuttal, questions |
| High school | Analytical oral | interpretation, structure, academic language |
| University | Seminar / poster | figures, citations, Q&A |
| Researcher | Conference talk / poster | findings, limitations, discussion |
| Professional | Business presentation / pitch | audience needs, decisions, asks |

Teach planning, slide design, speaking pace, pauses, accessibility, rehearsal, time management, and handling questions. IB Individual Oral and Extended Essay reflection are distinct formal activities, not generic presentation exams.

## 日本語訳

**プレゼンテーションの学習パス（日本語訳）**

| 段階 | 課題 | 中心となるスキル |
|---|---|---|
| 小学校 | Show & Tell | 順序立て、アイコンタクト、簡単な視覚資料 |
| 小学校高学年 | 情報提供型／説得型スピーチ | 導入、理由、締めくくり、時間配分 |
| 中学校 | ディベート／研究発表 | 根拠、反駁、質問 |
| 高校 | 分析的な口頭発表 | 解釈、構成、学術的な言葉遣い |
| 大学 | ゼミ発表／ポスター | 図表、引用、質疑応答 |
| 研究者 | 学会発表／ポスター | 研究結果、限界、考察 |
| 社会人・専門職 | ビジネスプレゼン／ピッチ | 聞き手のニーズ、意思決定、依頼事項 |

構想、スライドデザイン、話す速さ、間の取り方、アクセシビリティ、リハーサル、時間管理、質問への対応を教えます。IBの個人口述（Individual Oral）と課題論文（Extended Essay）の振り返りは、それぞれ独立した正式な活動であり、一般的なプレゼンテーション試験ではありません。
